# Fonts

Both are variable fonts, latin subset, taken from Fontsource 5.3.0 and
licensed under the SIL Open Font License 1.1.

- `inter-latin-wght-normal.woff2`: [Inter](https://rsms.me/inter/), for everything.
- `jetbrains-mono-latin-wght-normal.woff2`: [JetBrains Mono](https://www.jetbrains.com/lp/mono/),
  for what is copied to a terminal: clone URLs, commands, keys.
